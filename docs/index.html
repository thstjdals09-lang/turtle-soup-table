진상입니다

이상한 이야기 한 그릇이 나옵니다. 출제자 AI는 진상을 알고 있지만 네, 아니오, 관계없음, 애매함 네 마디밖에 하지 않아요. 같은 방에 앉은 사람들과 질문을 주고받으며 이야기의 바닥까지 떠 보세요.

  1. 1. 사진과 한 줄처음 보이는 건 현장 사진, 문제 한 줄, 키워드 개수뿐이에요. 사진 아래 현장 메모를 눌러 사물을 살펴보세요.
  2. 2. 네·아니오로 묻기질문 하나에 +1문. 누가·왜·어떻게처럼 열린 질문은 반려되고 세지 않아요.
  3. 3. 15·30·45문 단서문수가 차면 단서 사진이 한 장씩 열려요. 급하면 +10문 내고 긴급 열람. 50문이 되거나 스스로 질문을 끝내면 최종 답안 1회.
  4. 4. 진상 제출키워드를 모두 담아 설명하면 해결. 오답 +5문, 포기 +25문, 보너스 키워드 −3문. 적을수록 이겨요.

한 숟갈 15문 이하한 그릇 25문 이하두 그릇 35문 이하냄비째 50문 이하식은 수프 포기·실패
